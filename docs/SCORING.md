# 점수 산정 기준

`lz`가 두 나선을 어떻게 채점하는지 설명합니다. 상수는 전부 코드에서 직접
뽑은 실제 값이며 출처가 명시되어 있습니다.

> **먼저 읽을 것**
> 이 점수는 **순위이지 에너지가 아닙니다.** 단위가 kcal/mol처럼 보이지만
> 어떤 데이터셋에도 피팅되지 않았습니다. −12가 −6보다 두 배 세게 붙는다는
> 뜻이 아니라 "더 유망하다"는 뜻입니다.

---

## 전체 구조

```
score = w_core × E_core  +  w_elec × E_elec  +  w_helix × E_helix
```

| 항 | 기본 가중치 | 내용 |
|---|---|---|
| `E_core` | 1.0 | *a*/*d* 코어 패킹 |
| `E_elec` | 1.0 | *g*↔*e'* 염다리 |
| `E_helix` | **0.5** | 나선 성향 |

**음수 = 안정화**가 일관된 부호 규약입니다.

세 항으로 나눈 것은 임의가 아니라 **물리적으로 분리 가능하기 때문**입니다.
소수성 매몰, 정전기, 접힘 비용은 서로 다른 메커니즘이라 각각 독립적으로
보정할 수 있습니다.

나선 항에만 0.5가 붙은 이유: 나선 성향은 접힌 상태와 **풀린 상태 양쪽에**
영향을 주므로 순효과가 절반쯤입니다.

가중치는 `params.DEFAULT_WEIGHTS`에 있고 `lz calibrate`로 덮어쓸 수 있습니다.

---

## 왜 이런 계산이 가능한가 — 기하가 고정되어 있어서

일반적인 단백질-단백질 결합 예측이 어려운 이유는 **어디에 어떤 자세로
붙는지 모르기 때문**입니다. Coiled coil은 그 답이 정해져 있습니다 — 평행
이중나선, 헵타드 레지스터가 맞물린 상태.

그래서 문제가 "어디에 붙나"에서 **"얼마나 세게, 얼마나 선택적으로 붙나"**
로 축소됩니다. 서열 수준 채점이 성립하는 이유가 이것입니다.

7잔기 반복에서 각 위치가 상대 나선을 향하는 정도(Crick 이상 기하에서 측정,
`structure.IDEAL_PROFILE`):

| 위치 | 코사인 | 성격 |
|---|---|---|
| **d** | +0.888 | 정면으로 상대를 향함 |
| **a** | +0.810 | 정면 |
| g | +0.262 | 가장자리 |
| e | +0.174 | 가장자리 |
| c | −0.578 | 바깥 |
| b | −0.671 | 바깥 |
| f | −0.973 | 정반대 |

그래서 **a/d만 코어로, g/e만 정전기로** 계산합니다. b/c/f는 용매에 노출되어
파트너 선택에 거의 기여하지 않으므로 코어·정전기 항에서 제외하고 나선
성향에만 반영합니다.

## (1) 코어 패킹 — `E_core`

각 *a*/*a'*, *d*/*d'* 층마다 다음을 더합니다.

```
층 에너지 = 매몰 보상(잔기1) + 매몰 보상(잔기2)
          + 쌍 보정
          + 부피 불일치 벌점
          + 묻힌 동일 전하 벌점
          + 불만족 극성 벌점
```

### 매몰 보상 — 위치마다 다릅니다

`params.BURIAL`. 음수가 유리합니다.

**a 위치**

```
I -0.75   V -0.60   L -0.50   M -0.45   F -0.35   C -0.30   A -0.25
T -0.20   N -0.15   W -0.15   Y -0.15   S -0.05   Q -0.05   G +0.10
H +0.15   K +0.55   R +0.55   E +0.60   D +0.70   P +1.50
```

**d 위치**

```
L -0.90   M -0.60   F -0.38   C -0.33   I -0.30   A -0.30   V -0.22
W -0.10   Y -0.10   N -0.05   Q -0.05   T +0.05   S +0.05   G +0.20
H +0.20   K +0.60   R +0.60   E +0.65   D +0.75   P +1.50
```

*a*에서는 Ile가 Leu보다 유리하고, *d*에서는 Leu가 압도적입니다. Harbury의
규칙(β-분지 잔기가 *d*에 오면 삼량체·사량체로 감)을 인코딩한 것입니다.

### 쌍 보정 — **더하는 것이지 대체하는 것이 아닙니다**

`params.PAIR_BONUS`. 위의 매몰 합에 **추가로** 더해집니다.

| 층 | 쌍 | 보정 | 이유 |
|---|---|---|---|
| d | I–I | **+0.85** | Ile가 *d*에 오면 사량체로 감 |
| d | V–V | +0.40 | 같은 이유 (약하게) |
| d | M–M | +0.30 | Leu보다 못함 |
| a | N–N | **−0.70** | 계면 수소결합 (특이성 결정) |
| a | Q–Q | −0.50 | 같은 메커니즘 (약하게) |

> **이 "더한다"가 중요합니다.** 초기 버전은 쌍 값으로 매몰 합을 **대체**
> 했는데, 그러면 이종 쌍과 동종 쌍이 비교 불가능해집니다. 설계기가 그 틈을
> 찾아내 **코어 Leu를 전부 Ile로 바꿔버렸습니다** — 류신 지퍼를 설계하면서
> 류신을 없앤 것입니다. 되돌리지 마세요.

### 부피 불일치

```
벌점 = 0.012 × |V(잔기1) + V(잔기2) − 333.4|      (Å³당)
```

이상값 333.4 Å³는 **2 × Leu**입니다. 과밀 충전과 공동(cavity) 형성을 한
항으로 동시에 잡습니다.

Val–Val(*a* 위치)이 좋은 예입니다: 소수성이지만 두 곁사슬 합이 280 Å³라
**코어를 다 못 채웁니다.** 매몰 보상 −1.20에 부피 벌점 +0.64가 붙어
최종 **−0.56** — Leu–Leu의 −1.80에 한참 못 미칩니다.

### 묻힌 동일 전하 — **+1.10**

두 잔기가 모두 양전하(K/R)이거나 모두 음전하(D/E)일 때. 모델이 아는
가장 큰 단일 벌점입니다.

### 불만족 극성 — **+0.60**

둘 중 **하나만** 극성일 때. 소수성 환경에 수소결합 상대 없는 공여체·수용체가
남는다는 뜻입니다.

이것이 **Asn의 특이성을 만듭니다.** Asn은 Asn을 만나면 −0.70 보정을
받지만, Leu를 만나면 +0.60 벌점을 받습니다. 그래서 Asn은 Asn만 찾습니다.

## (2) g↔e' 염다리 — `E_elec`

평행 이중나선에서 한쪽 사슬의 *g*(i)는 상대 사슬의 *e*(i+5)를 마주봅니다.
**양방향 모두** 계산합니다.

| 조합 | 값 |
|---|---|
| 반대 전하 (K/R ↔ D/E) | **−0.45** |
| 같은 전하 | **+0.40** |
| 전하 ↔ 극성 | −0.10 |
| 그 외 | 0 |

**이것이 파트너 선택의 주 수단입니다.** 코어는 거의 모든 지퍼가 비슷하게
생겼기 때문에, 누가 누구와 짝이 되느냐는 대부분 여기서 결정됩니다.
Acid-p1 / Base-p1이 작동하는 원리이고, 직교 세트 설계기가 가장 먼저
찾아내는 수단이기도 합니다.

## (3) 나선 성향 — `E_helix`

두 사슬 **전체 잔기**의 평균 나선 성향입니다.

```
E_helix = Σ propensity(잔기) / 총 잔기 수
```

**이것이 유일한 문헌 실측값입니다** — Pace & Scholtz (1998) *Biophys J*
75:422, Ala = 0 기준 kcal/mol. 값이 클수록 나선을 이루기 어렵습니다.

```
A 0.00 | L 0.21  R 0.21  M 0.24  K 0.26 | Q 0.39  E 0.40  I 0.41
W 0.49  S 0.50  Y 0.53  F 0.54 | H 0.61  V 0.61  N 0.65  T 0.66
C 0.68  D 0.69 | G 1.00 | P 3.16
```

Gly나 Pro가 많으면 애초에 나선이 되지 않으므로 벌점을 받습니다.

## (4) 정렬 탐색

두 나선이 몇 헵타드 어긋나 맞물릴지는 미리 알 수 없습니다. 가능한 shift를
전부 채점하고 가장 좋은 것을 택하되 **두 가지 제한**이 있습니다.

| 상수 | 값 | 의미 |
|---|---|---|
| `MIN_OVERLAP_LAYERS` | 4 | 코어 층 4개(두 헵타드) 미만이면 채점 거부 |
| `MAX_SLIP_HEPTADS` | 1 | 최대 겹침에서 1헵타드 이상 미끄러질 수 없음 |

> **`MAX_SLIP_HEPTADS`를 풀지 마세요.** 제한이 없으면 나쁜 서열이 계면을
> 밀어 겹치는 층 수를 줄이는 방식으로 벌점을 회피합니다. 짧지만 깨끗한
> 계면이 긴 나쁜 계면을 이기기 때문입니다. 실제로 코어 Leu를 전부 Glu로
> 치환한 돌연변이가 야생형과 **같은 점수**를 받았습니다.

같은 길이·같은 오프셋이 보장된 경우(설계된 세트)에는 `shift=0`으로 고정해
탐색을 건너뜁니다 — 행렬 전체를 반복 채점하는 직교 설계에서 이 비용이
지배적이기 때문입니다.

## 계산 예시 — GCN4 호모다이머

```
python -m lz score RMKQLEDKVEELLSKNYHLENEVARLKKLVGER RMKQLEDKVEELLSKNYHLENEVARLKKLVGER
```

```
total        -9.47
  core       -6.96
  electro    -2.70
  helix      +0.38
  layers     10 (heptad shift +0)

  core h1  a    M-M  -0.81      core h3  d    L-L  -1.80
  core h1  d    L-L  -1.80      core h4  a    V-V  -0.56
  core h2  a    V-V  -0.56      core h4  d    L-L  -1.80
  core h2  d    L-L  -1.80      core h5  a    V-V  -0.56
  core h3  a    N-N  +0.26      core h5  d    R-R  +2.46
  elec h0  g-e' R-E  -0.45   (x6, 전부 반대 전하)
```

읽는 법:

- **`d L-L −1.80`** — 류신 지퍼를 류신 지퍼로 만드는 상호작용. 부피가 딱
  맞아 벌점 0.
- **`d R-R +2.46`** — Arg 두 개가 코어에 묻힘. 매몰 +1.20, 동일 전하
  +1.10, 부피 초과 +0.16. 모델이 아는 **최악의 층**입니다. 실제 구조에서
  이 말단 층은 형성되지 않습니다(2ZTA는 31잔기까지만 정렬되어 있음).
- **`a N-N +0.26`** — GCN4의 Asn16. **양수, 즉 불안정화합니다.** 이것이
  맞습니다 — Asn16을 Val로 바꾸면 GCN4는 더 안정해집니다. Asn이 사는
  이유는 안정성이 아니라 **특이성**입니다.
- **`elec` 6줄 전부 −0.45** — 전부 반대 전하. 잘 설계된 정전기 계면입니다.

## 파생 지표

### specificity (2체)

```
specificity = score(후보, 표적) − score(후보, 후보)
```

음수면 후보가 자기 호모다이머보다 표적을 선호합니다. **순위는 결합력이
아니라 이 값으로 매깁니다** — 잘 붙어도 자기들끼리 더 뭉치면 용액에서
표적을 만나지 못하기 때문입니다.

### margin vs set (집합 전체)

```
margin = score(의도한 쌍) − min(세트 내 모든 원치 않는 상호작용)
```

비교 대상이 자기 호모다이머가 아니라 **세트 안의 최악의 경쟁자**이며,
대개 다른 쌍의 사슬입니다.

### 설계 마진 (hinge)

음성 설계 항은 **hinge**이지 선형이 아닙니다.

```
penalty = max(0, E(원하는 쌍) + margin − E(경쟁자))
```

| 상수 | 값 | 쓰이는 곳 |
|---|---|---|
| `SPECIFICITY_MARGIN` | 1.0 | 단일 파트너 설계 |
| `DEFAULT_CROSS_MARGIN` | **3.0** | 직교 세트 설계 |

> **선형으로 바꾸지 마세요.** 선형이면 자기 호모다이머를 망가뜨리는 것만
> 으로 점수가 무한정 내려가고, 설계기가 실제 계면을 포기합니다.
>
> **그리고 3.0을 낮추지 마세요.** 3쌍 x 3시드로 측정한 최악 마진 평균:
>
> | 마진 | 공동 설계 | 독립 설계 |
> |---|---|---|
> | 1.0 | −1.20 | **−1.89** (공동 설계가 더 나쁨) |
> | 2.0 | −1.98 | −2.07 (차이 없음) |
> | 3.0 | **−2.72** | −1.81 |
> | 4.0 | **−3.11** | −1.41 |
>
> cognate 점수가 −20 근처인데 경쟁자를 1만큼 이기는 것은 아무것도 아닙니다.
> hinge가 즉시 꺼져 탐색이 쌍들을 차별화하기도 전에 멈춥니다.

## 구조에서 레지스터 측정

구조가 있으면 레지스터를 예측하지 않고 측정합니다. 각 잔기의 CB가 상대
나선 축을 얼마나 똑바로 향하는지(코사인)를 구하고, 7가지 오프셋 각각에
대해 앞의 이상 프로파일과의 **Pearson 상관계수**를 계산해 최고점을 택합니다.

상관계수를 쓰는 이유: 실제 구조는 이상 기하와 **모양은 같고 진폭만
작습니다**(2ZTA는 코어 코사인이 0.1~0.2 낮음). 척도 불변 측도라야 모양만
보고 "이상적이지 않다"는 이유로 벌점을 주지 않습니다.

> **a/d만 쓰면 안 됩니다.** 초기 버전은 a/d 평균 코사인만 썼는데, *g*도
> 코사인이 +0.4 정도라 "g를 a로 착각한" 오프셋이 진짜 d 류신들을 그대로
> 가지면서 거의 같은 점수를 받습니다. 2ZTA에서 마진이 0.098밖에 안 나와
> **교과서적 참조 구조에 "기하가 애매하다"고 경고**했습니다. 7위치 전부를
> 쓰자 0.912로 올라갔습니다. *g*(+0.26)와 *e*(+0.17)의 비대칭이 축퇴를
> 깨는 정보입니다.

경고 임계값 (`structure.AMBIGUOUS_FIT` / `AMBIGUOUS_MARGIN`):

| | fit (r) | margin |
|---|---|---|
| 경고 기준 | < 0.60 | < 0.05 |
| 이상적 Crick 기하 | 0.999 | 0.370 |
| 2ZTA (GCN4) | 0.912 | 0.120 |

**실제 구조 1개로만 보정되어 있습니다.** margin이 완벽한 구조에서도 작은
이유는 *a*와 *d*가 51°밖에 떨어져 있지 않아 3~4칸 밀린 레지스터가 **진짜로**
비슷하기 때문입니다. 그래서 경고의 주 신호는 margin이 아니라 절대 적합도입니다.

## 상수의 출처 — 가장 중요한 절

`params.py`에는 **두 종류**가 섞여 있고 파일에 어느 쪽인지 전부 표기되어
있습니다.

### 실측값 — 하나뿐입니다

`HELIX_PROPENSITY` — Pace & Scholtz (1998) *Biophys J* 75:422.

### 휴리스틱 — 나머지 전부

매몰 보상, 쌍 보정, 부피 벌점 0.012, 동일 전하 1.10, 불만족 극성 0.60,
염다리 ±0.45/0.40. 확립된 **정성적** 규칙을 손으로 인코딩한 것입니다:

- *d*의 Leu 선호, Ile가 *d*에 오면 삼량체·사량체 — Harbury et al. 1993,
  *Science* 262:1401
- GCN4 Asn16의 이량체·배향 특이성 — O'Shea et al. 1991, *Science* 254:539
- g↔e' 염다리가 파트너 선택을 결정 — O'Shea, Lumb & Kim 1993,
  *Curr Biol* 3:658
- 묻힌 전하의 불안정화

**어떤 데이터셋에도 피팅되지 않았습니다.** 그래서:

- 점수는 **비교에만** 쓸 수 있고 절대값은 인용하면 안 됩니다
- `PairScore.predicted_tm`은 보정 전까지 **무의미합니다**
  (`TM_INTERCEPT 25.0`, `TM_SLOPE −4.0`은 자리표시자)

### 보정하는 법

문헌에는 같은 꼴의 3항 분해를 실험 Tm에 회귀로 맞춘 모델이 있습니다
(bCIPA, Hagemann/Keating). `lz calibrate`가 그 경로입니다.

```bash
python -m lz calibrate my_tm_data.csv --out weights.json
python -m lz screen --pdb my_zipper.pdb --weights weights.json
```

CSV 열: `sequence1,sequence2,tm`. 최소제곱으로 세 항의 가중치를 맞추고
R²/RMSE를 보고합니다. 측정값 20개 정도면 순위 신뢰도가 크게 올라갑니다.

**실험 Tm 데이터가 이 프로젝트에 가장 큰 기여입니다.**

---

## 모델이 다루지 않는 것

- **역평행 배향** — 평행 이중나선만 가정합니다. 역평행 구조에서는 모든
  점수가 무의미하며 앱이 경고합니다.
- **삼량체·사량체** — Ile가 *d*에 오면 벌점을 주는 식으로 *간접적으로만*
  반영됩니다. 올리고머 상태를 예측하지는 않습니다.
- **나선 밖 영역** — 링커, 말단, 구조화되지 않은 부분의 기여 없음.
- **용매·이온 조건** — pH나 염 농도가 염다리에 미치는 영향 없음.
- **동역학** — 결합 속도나 수명이 아니라 평형 선호도만 봅니다.

이것들이 구조 예측(ColabFold / AlphaFold-Multimer)과 실험 검증이 여전히
필요한 이유입니다.
